About the project

CD Digital Chess is a personal chess study web app.

It is independently developed and maintained to provide practical browser-based tools for studying positions, organizing lessons, solving puzzles, analyzing games, and teaching chess.

What it is

CD Digital Chess is a personal software project available through a web browser. It brings chess study, training, and coaching tools together in one workspace.

Who it is for

The app is designed for chess coaches, students, and independent learners who want structured tools for exploring positions and preparing lessons.

What the app provides

  • Interactive position setup and study boards
  • Structured chess lessons and opening material
  • Puzzles and position-training tools
  • Game and position analysis features
  • Lesson preparation and coaching workflows
  • Browser-based access without a desktop installation

CD Digital Chess is an independent personal web application. It is not a chess federation, governing body, hardware manufacturer, or major commercial chess platform.

# Sicilian Defense Chapter & Page Authoring Guide

This guide details how to author, edit, format, and audit chapters and pages in the **Sicilian Defense Opening Book** (`apps/opening-book-sicilian`).

---

## 1. Directory & File Conventions

All chapter manuscripts reside in:
```text
apps/opening-book-sicilian/app/content/chapters/
```

- **Naming format**: `chapter-N-sicilian.md` where `N` is an integer starting from 1 (e.g., `chapter-1-sicilian.md`, `chapter-2-sicilian.md`, `chapter-6-sicilian.md`).
- **Contiguity**: Chapter numbers must be contiguous starting from Chapter 1.
- **Generated Catalog**: The catalog in `app/chapter-catalog.generated.ts` is auto-generated by the CLI workflow. Never edit it manually.

---

## 2. Chapter & Page Document Structure

Every chapter Markdown file must conform to this structure:

```markdown
## Page 96

# Chapter 6: c3 Sicilian – Main Line

**FEN:**
`rnbqkbnr/pp1ppppp/8/2p5/4P3/2P5/PP1P1PPP/RNBQKBNR b KQkq - 0 2`

<!-- SOURCE MOVE REFERENCE: Introductory moves. -->
**1.e4 c5 2.c3 Nf6 3.e5 Nd5 4.d4 cxd4 5.Nf3**

Introductory discussion of the 5.Nf3 main line...

### Variation Index

1.e4 c5 2.c3 Nf6 3.e5 Nd5 4.d4 cxd4 5.Nf3

- A) 5...e6 97
- B) 5...Nc6 102
  - B1) 6.Bc4 103
  - B2) 6.cxd4 107

## Page 97

<!-- FEN: rnbqkb1r/pp1p1ppp/4pn2/8/2Pp4/5N2/PP2PPPP/RNBQKB1R w KQkq - 0 6 -->
**5...e6 6.cxd4 d6**

Analysis of the 5...e6 setup on Page 97...
```

### Key Formatting Rules

1. **Top-level Title (`# Title`)**: Exactly **one** level-1 heading per chapter.
2. **Page Boundaries (`## Page N`)**:
   - Must match the printed/authoritative source page numbers.
   - Must be **strictly contiguous and ascending** (e.g., Page 96, 97, 98...).
3. **No Non-Breaking Spaces**: Do not use `\u00a0`, `&nbsp;`, `&#160;`, or `&#xa0;`. Use regular spaces.

## 3. Chess Positions & FEN Diagrams

Every page must have at least one FEN anchor. There are two ways to define positions:

### A. Visible Board Diagram
Displays an interactive chessboard in the chapter text:
```markdown
**FEN:**
`rnbqkbnr/pp1ppppp/8/2p5/4P3/2P5/PP1P1PPP/RNBQKBNR b KQkq - 0 2`
```

### B. Invisible Synchronization Anchor
Synchronizes the active board state without rendering a new static diagram in the text flow:
```markdown
<!-- FEN: rnbqkbnr/pp1ppppp/8/2p5/4P3/2P5/PP1P1PPP/RNBQKBNR b KQkq - 0 2 -->
```

> [!TIP]
> Use invisible FEN anchors at the top of a page or before a subvariation to reset/synchronize the interactive move tree with the board.

## 4. Move Notation & Navigation

The move resolver (`app/lib/markdown-moves.ts`) parses chess notation into clickable, interactive move tokens. Follow these conventions:

### A. Move Token Syntax
- **Bold moves**: `**1.e4** **c5** **2.Nf3**` or `**1.e4 c5 2.Nf3**`
- **Subvariations**: Enclosed in parentheses `(2.c3 Nf6 3.e5 Nd5)`
- **Sibling branches**: Separated by `;` or `or`:
  ```markdown
  (2...Nc6 3.d4; 2...d6 3.Nbc3)
  (10.bxc4 Be6= or 10...Be7=)
  ```
- **Evaluation & Annotation Glyphs**:
  - `!` (good move), `?` (mistake), `!?` (interesting), `?!` (dubious)
  - `+` (check), `#` (checkmate)
  - `=` (equal), `⩲` / `⩱` (slight advantage), `±` / `∓` (advantage), `+-` / `-+` (decisive)
  - `⇆` (counterplay), `→` (attack), `∞` (unclear)
  - `N` (theoretical novelty, e.g. `14...Bh4!N-+`)
- **Prose Mentions without Interaction**:
  To prevent historical game moves or non-interactive introductory moves from interfering with the active board, prefix them with:
  ```markdown
  <!-- SOURCE MOVE REFERENCE: Introductory moves. -->
  **1.e4 c5**
  ```

## 5. Chapter Management CLI

Use the built-in chapter management scripts to scaffold, append, sync, and validate:

### 1. View Catalog Status
```powershell
node scripts/chapter-system.mjs status
```
Displays all detected chapters, page ranges, total pages, and validated FEN counts.

### 2. Scaffold a New Chapter
```powershell
# Create the next contiguous chapter with 5 default pages
node scripts/chapter-system.mjs new-chapter --title "c3 Sicilian – Main Line" --pages 5

# Or specify a custom starting page
node scripts/chapter-system.mjs new-chapter --title "c3 Sicilian – Main Line" --pages 10 --start-page 96
```
This automatically creates `chapter-N-sicilian.md` and updates `app/chapter-catalog.generated.ts`.

### 3. Append Pages to an Existing Chapter
```powershell
# Append 2 pages to Chapter 5
node scripts/chapter-system.mjs add-page 5 --count 2
```

### 4. Synchronize Catalog
```powershell
node scripts/chapter-system.mjs sync
```
Updates `app/chapter-catalog.generated.ts` from all markdown files in `app/content/chapters/`.

### 5. Validate & Check Integrity
```powershell
node scripts/chapter-system.mjs check
```
Verifies FEN legality, contiguous page numbers, level-1 titles, and ensures the generated catalog is up to date.

### 6. Deep Chapter Audit
```powershell
npm run chapters:audit -- --chapter 5 --markdown app/content/chapters/chapter-5-sicilian.md --expected-first-page 77 --expected-pages 19
```
Performs a deep traversal of all move tokens, branch lookahead, anchor recovery, and prose coverage.

### 7. Run Full Test Suite
```powershell
npm test
```
Runs the entire Vite build, static route generation, anchor verification, and unit tests.

Files, Ranks, and Diagonals

The chessboard is divided in three useful ways: vertical files, horizontal ranks, and slanting diagonals.

FilesLearn the vertical columns named a through h.
RanksLearn the horizontal rows numbered 1 through 8.
DiagonalsFind slanting connected squares across the board.
AccuracyUse editable HTML/CSS boards instead of unreliable generated diagrams.

Three Ways to Divide the Board

A chessboard can be described by direction. This helps players name squares quickly and explain moves clearly.

F FilesVertical columns named with letters: a, b, c, d, e, f, g, h.
R RanksHorizontal rows numbered: 1, 2, 3, 4, 5, 6, 7, 8.
D DiagonalsConnected squares that run slanting across the board.
Improved visual format

Remember

Use direction words to describe the board correctly.

Files go up and downThey are vertical and named with letters.
Ranks go left and rightThey are horizontal and named with numbers.
Diagonals are slantingEach square touches the next corner-to-corner.
Square names combine bothFor example, b7 is on the b-file and the 7th rank.
7

Quick Check

Review the main ideas before moving to the next lesson.

1. What is the blue file called?

Answer: the b-file.

2. What is the orange rank called?

Answer: the 7th rank.

3. Which squares form the e1–h4 diagonal?

Answer: e1, f2, g3, h4.

4. Which diagonal goes from a1 to h8?

Answer: the yellow-star diagonal.

Why is this version safer than generated diagram images?

The squares and coordinates are coded directly in the HTML, so the b-file, 7th rank, a1 dark square, and h1 light square remain correct and easier to edit.

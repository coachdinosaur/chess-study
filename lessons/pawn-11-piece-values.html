Piece Values

Learn the basic value of each chessman. These values help players compare material, make trades, and understand which side has a material advantage.

King = the gameThe king is not counted in points because checkmate ends the game.
Queen = 9The queen is the strongest point-valued piece.
Rook = 5A rook is worth more than a bishop or a knight.
Minor pieces = 3Bishops and knights both have a basic value of 3 points.
Basic chess values
King = the game. Queen = 9. Rook = 5. Bishop = 3. Knight = 3. Pawn = 1.

Values at a Glance

Each chessman has a basic value. The king is special because its value is the whole game.

King

The king is the most important piece.

Value The game

Queen

The queen is the strongest point-valued piece.

Value 9 points

Rook

The rook is more valuable than a bishop or knight.

Value 5 points

Bishop

The bishop moves on diagonals.

Value 3 points

Knight

The knight has the same basic value as a bishop.

Value 3 points

Pawn

The pawn has the smallest basic value.

Value 1 point
Important: These are basic values for beginners. In a real game, the exact usefulness of a piece can change depending on the position.

Why the King Has No Point Value

The king is the most important piece. You do not trade the king for points.

If your king is checkmated, you lose the game.

That is why the king’s value is written as the game, not as a number of points.

Key idea

Every other chessman can be captured. The king is never captured; the game ends when the king is checkmated.

Review Questions

Check if students can recall the values without looking at the chart.

What is the value of the queen?

The queen is worth 9 points.

Which two chessmen are worth 3 points?

The bishop and the knight are each worth 3 points.

Why is the king not worth points?

The king’s value is the game itself. If your king is checkmated, you lose.

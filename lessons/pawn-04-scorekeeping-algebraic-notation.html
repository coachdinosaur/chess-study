What is Algebraic Notation?

Algebraic Notation is the common method used to read and write chess moves.

Before you can record a full move, you must know the address of each square on the chessboard.

Every square has one file letter and one rank number. Combine them to name the square.

Square address = file letter + rank number
2

How to find the name of a square

Use the bottom letters and the left-side numbers.

1
Look down from the square.
Find the file letter at the bottom of the board.
2
Look left from the square.
Find the rank number on the left side of the board.
3
Combine them.
The letter comes first, then the number.

For the highlighted square, looking down gives d. Looking left gives 5. So the square is d5.

3

More examples

Use the same method for every square on the board.

Blue star: c4

Red star: h8

4

Using notation in real games

Chess players use Algebraic Notation to keep a written record of the game.

A move such as e4 tells us that a pawn moved to the square e4.

A move such as Nf3 tells us that a knight moved to the square f3. The letter N means knight.

This lesson focuses first on square names. Once square names are easy, full move notation becomes easier to learn.

5

Quick practice

Answer by saying the letter first, then the number.

Practice 1: What is the square on file d and rank 5?

Answer: d5.

Practice 2: What is the square on file c and rank 4?

Answer: c4.

Practice 3: What is the square on file h and rank 8?

Answer: h8.
